# BizPrice — Smart Business Finance Tracker 💰

> Aplikasi mobile cross-platform untuk membantu pelaku UMKM Indonesia dalam menghitung **HPP (Harga Pokok Penjualan)**, **BEP (Break Even Point)**, dan mengelola keuangan bisnis secara cerdas.

---

## 📱 Tentang Aplikasi

**BizPrice** adalah aplikasi Flutter yang dirancang khusus untuk UMKM Indonesia agar dapat mengelola keuangan bisnis dengan mudah tanpa perlu keahlian akuntansi. Dikembangkan sebagai Project Based Learning (PBL) Semester 4 oleh Kelompok 4, Politeknik Negeri Malang.

---

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 📊 **Kalkulator HPP** | Hitung harga pokok penjualan secara otomatis |
| 📈 **Analisis BEP** | Tentukan titik impas usaha dengan tepat |
| 💾 **Riwayat Transaksi** | Simpan dan pantau catatan keuangan |
| 🎯 **Target Tabungan** | Atur dan lacak target keuangan bisnis |
| 💡 **Insight Bisnis** | Rekomendasi cerdas berdasarkan data keuangan |
| 📝 **Catatan Bisnis** | Tambahkan catatan penting untuk usahamu |

## 🚀 Cara Menjalankan

**Prasyarat**: Flutter SDK sudah terinstall ([flutter.dev](https://flutter.dev))

```bash
# Clone repository
git clone https://github.com/adzikraaa/PBL-FinanceTracker-Kelompok4.git

# Masuk ke direktori
cd PBL-FinanceTracker-Kelompok4

# Install dependencies
flutter pub get

# Jalankan aplikasi
flutter run
```
